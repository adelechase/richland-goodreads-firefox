# Privacy Policy for Richland Library on Goodreads

Last updated: November 11, 2026

Richland Library on Goodreads is a Firefox extension that checks Richland Library availability for books displayed on Goodreads.

## Information the extension uses

To perform its primary function, the extension reads book information visible on the Goodreads page you are viewing, including the book title, author, and, when available, ISBN.

The extension sends book-identifying information as search terms to the following services so it can retrieve library availability information:

- Richland Library's Polaris catalog
- Richland Library's OverDrive/Libby collection
- Hoopla Digital

This transmission is necessary for the extension to determine whether a book is available and in which formats.

## Hoopla account information

For Hoopla searches, the extension may open temporary hidden Hoopla tabs in Firefox so Hoopla can render search results using the browser session you already have. The extension does not ask for, read, store, or transmit your library card number, Hoopla password, or other login credentials. Temporary Hoopla tabs are closed after the search completes or times out.

## Storage and analytics

The extension does not operate its own server and does not send data to the developer. It does not use analytics, advertising trackers, or telemetry. It does not sell or share user data for advertising or profiling.

The extension does not intentionally retain a history of the books you view or search. Third-party services contacted by the extension may process requests according to their own privacy policies and server logs.

## Why Firefox asks for website content permission

Firefox classifies text and other information read from a webpage as `websiteContent`. The extension requires this permission because it reads book information from Goodreads and transmits that information to library and ebook services to perform availability searches.

## Changes to this policy

If the extension's data practices change, this policy will be updated and the extension's Firefox data-collection declaration will be updated as required.
