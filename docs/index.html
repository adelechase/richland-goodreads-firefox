Richland Library on Goodreads

This Firefox extension adds Richland Library availability information directly to Goodreads book pages and book lists. It checks the library's physical collection, Libby, and Hoopla so I can see whether a book is available to borrow without opening three separate searches.

How to Install the Richland Library on Goodreads Extension

  1. Use Firefox 140 or newer, then select the purple installation link below.
  2. If Firefox asks you to add the extension, review the permissions and follow the prompts. If the .xpi file downloads instead, open about:addons in Firefox, select the gear menu, choose Install Add-on From File, and select the downloaded file.
  3. Open or refresh Goodreads to begin using the extension. For Hoopla availability, sign in to Hoopla in the same Firefox browser using your Richland Library account.

Install version 2.5.1 for Firefox

Firefox checks for newer signed releases according to its add-on update settings, so you do not need to reinstall the extension after each update.

How to Use the Extension

  1. Open a book's page on Goodreads or browse a Goodreads book list. The extension checks each book it recognizes and adds a Richland Library information panel or compact results card.
  2. Read the availability information by format. Physical copies can show how many are available and how many holds have been placed. Digital results appear separately for Libby and Hoopla when a match is found.
  3. Select a linked format to open its source, or use View in catalog to open the corresponding Richland Library catalog search.
  4. If Hoopla results are missing, make sure you're signed into Hoopla in Firefox with your Richland Library account, then refresh Goodreads. You do not enter your library card number into the extension.

How Book Information Is Found and Displayed

Richland Library holdings

The extension searches the Richland Library catalog for a matching book and displays physical formats and copy availability when the catalog provides those counts. It may also show holds. When it cannot retrieve a live count, it indicates that availability was not shown rather than supplying a number.

Libby availability

Libby results come from Richland Library's OverDrive collection. Available formats and borrowing status are displayed separately from the physical holdings, with links to the corresponding digital records when available.

Hoopla eBooks and eAudiobooks

Hoopla eBook and eAudiobook searches run independently, so one format's search does not stop the other. The extension may briefly open hidden browser tabs to check Hoopla using your existing signed-in session; it closes its temporary tabs after the checks finish or time out.

Matching books and interpreting results

The extension reads a book's title and author from Goodreads, along with an ISBN when one is available. It uses this information to search the catalog and digital services. Editions, subtitles, and differences in catalog records can affect matching, so Not in collection means the lookup did not find a match, not necessarily that Richland Library has no copy. If a result looks incorrect, double-check the title manually in the library catalog, Libby, or Hoopla.

Privacy and permissions

The extension sends book-identifying search information to Richland Library's catalog, OverDrive/Libby, and Hoopla to check availability. It does not ask for or store your library card number or Hoopla password, operate a developer server, use analytics, or intentionally keep a reading history. See the privacy information for more details about the sites contacted and Firefox permissions.
