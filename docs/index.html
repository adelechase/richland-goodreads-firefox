Richland Library on Goodreads

A Firefox add-on that shows Richland Library physical holdings, live Libby availability, and Hoopla eBook and eAudiobook availability while you browse books on Goodreads.

Install version 2.5.1 for Firefox

Firefox 140 or newer. If downloaded instead of installed, open about:addons, use the gear menu, and choose Install Add-on From File.

You have to sign in to Hoopla in Firefox with your Richland Library account. You do not need to enter your library card number into the extension.
