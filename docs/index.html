Richland Library on Goodreads

A Firefox extension that shows Richland Library's physical holdings, live Libby availability, and Hoopla eBook and eAudiobook results while you're browsing books on Goodreads.

Current version: 2.5.1. Release status: Source code is available; a Mozilla-signed installation file has not yet been published. Please don't install an unsigned ZIP as a regular Firefox add-on.

Requires Firefox 140 or newer. For library-specific Hoopla results, sign in to Hoopla in Firefox with your Richland Library account. You do not need to enter your library card number into the extension.

Try it in Firefox (temporary development installation)

  1. Open the GitHub repository. Select Code and then Download ZIP, and extract the files to a folder.
  2. In Firefox, open about:debugging, select This Firefox, then Load Temporary Add-on.
  3. Select manifest.json from the extracted extension folder.
  4. Open or refresh a book page on Goodreads to see the library lookups.

Temporary add-ons are removed when Firefox closes. When a Mozilla-signed version becomes available, installation information will be posted here.
